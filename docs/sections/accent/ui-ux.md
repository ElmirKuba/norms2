# Акцент — UI/UX (Фаза 2)

> Экраны, дизайн-язык, доступность, тон. Наследует дизайн фазы 1 ([ADR-0025](../../decisions/0025-ui-ux-design-language.md)): тёмная тема + переключатель, **чистый SCSS** (без Tailwind), свои компоненты, модалки через **MatDialog** ([ADR-0026](../../decisions/0026-modal-system.md)); графики прогресса — **ApexCharts** за своим wrapper `app-chart` ([ADR-0055](../../decisions/0055-progress-charts-apexcharts.md)). Эндпоинты — [`api-contracts.md`](./api-contracts.md). Тон/принципы — [README §6](./README.md).

## 1. Тон: «интерес, не страх» (критично)
Каждый текст двигает вперёд, не давит назад. Это не косметика — это механика удержания «Васи».

| Ситуация | ❌ страх | ✅ интерес |
|---|---|---|
| Задача не сделана | «Не выполнено» | «Серия ждёт продолжения» |
| Серия сброшена | «Серия прервана 😔» | «Comeback начинается сегодня» |
| Цель отстаёт | «Отстаёшь от плана» | «12 / 77 — продолжаем» |
| Пустой экран | «Нет данных» | «День начинается — первый шаг?» |
| Срыв анти-привычки | «Срыв» | «Новая попытка» |
| Плохой день (recovery) | — | «Сегодня хватит минимума. Это уже победа» |

## 2. Дизайн-язык
- Тёмная по умолчанию + toggle (CSS-переменные, как фаза 1).
- Минимал с теплотой: мягкие скругления, тёплый акцент, воздух. Цифры читаются «с метра» (% дня, серия, уровень).
- **Один экран — одно главное решение. Один день — один главный прогресс.**
- Мгновенный отклик: оптимистичный UI, toast «+N», анимация чекбокса. Ошибка → откат + тост.

## 3. Доступность (accessibility-first, R21 — с самого начала, НЕ «потом»)
Аудитория включает людей в тяжёлом состоянии (депрессия/тревога/ADHD/боль), поэтому a11y — в MVP:
- клавиатурная навигация, видимый focus-ring; ARIA-роли на кастомных компонентах;
- контраст ≥ 4.5:1 (мелкий) / 3:1 (крупный);
- `prefers-reduced-motion` отключает нерезкие анимации;
- простой язык, низкая когнитивная нагрузка, крупные тап-таргеты;
- один главный шаг на экран (особенно важно для ADHD/перегрузки);
- кандидаты (волной): голосовой ввод, offline-core.

## 4. Карта экранов (lazy feature `accent`)
```
/accent                       дашборд (главный)
/accent/checkin               чек-ин состояния + тренды самочувствия 7/30/90 (из CheckIn)
/accent/goals  /goals/:id     цели (список / деталь: % + прогресс-бар, график динамики, прогноз, вехи)
/accent/habits  /habits/:id   привычки + дневной чеклист (вкладки Сегодня / Шаблоны)
                              деталь (2.7.3): «что было с этой привычкой» — лента дней и движения планки
/accent/todos                 дела, идеи и покупки ОДНИМ списком (2.10): запись одной строкой,
                              подзадачи, ожидание события, архив. Вкладок по видам нет
                              (17.08.2026) — вид это пометка записи, а не раздел
/accent/habits (Сегодня)      выбор дня — календарь: кликаются только дни с записями, будущее
                              закрыто, прошлое без кнопок действий
/accent/micro-wins            микро-победы (быстрый список «сделать сейчас»)
/accent/anti-habits  /:id     анти-привычки (живой таймер дн:ч:мин:сек)
/accent/obstacles      /:id   препятствия + контрмеры (деталь: контрмеры сверху, лента столкновений)
                              (маршрута /accent/weekly НЕТ — ADR-0069: неделя живёт
                              блоком на дашборде, планер не делаем)
/accent/lessons               журнал уроков (якорь)
/accent/stats                 постоянство (итог + окно) и достижения — ✅ 2.9
/accent/supporters            поддержка / круг доверия (MVP — реестр)
```

Каждый экран обрабатывает 4 состояния: **loading** (скелетоны), **empty** (CTA-призыв, не вина), **error** (+ «Повторить»), **loaded**.

## 5. Дашборд (кокпит)

**Что собрано в 2.11** (mobile-first стек, сверху вниз):
1. **«Сейчас»** — герой экрана: одно дело и одна кнопка. Считается **по правилам** из готовых данных (просрочка → задача дня → микро-победа → похвала «на сегодня всё»); чек-ин в 2.8 не добавит блок, а уточнит выбор внутри этого же механизма.
2. «Сегодня»: % дня + короткий список задач (до 5); полный чеклист — на `/accent/habits`.
3. Активные цели: до 5, фокусные первыми.
4. «Держусь»: живые счётчики (момент старта приходит с бэка, тикает фронт).
5. Просроченные разовые задачи.
6. Строка «накрыло? → Столкнулся» — если у человека есть свои препятствия: в плохую минуту главный экран должен давать самый короткий путь к помощи, а не только отчёт о делах.
7. Пауза раздела (была и раньше).

**Раскладка — бенто-сетка (2.11).** Иерархия делается **размером плитки**, а не цветом: «Сейчас» — на всю ширину, «Сегодня» — крупная плитка (половина ширины, две строки), цели — широкая, «Держусь» и просрочка — компактные. Точки перелома: <768px — одна колонка (порядок = приоритет), 768–1199 — две, ≥1200 — четыре. **Героев не больше двух** — иначе глазу не за что зацепиться. Пустые блоки не рисуются, поэтому спаны заданы так, что оставшиеся плитки перетекают без дыр.

**Типографика плиток.** Где есть число — **значение крупнее подписи** (28% и «5 из 18» мелко под ним; «4 дн.» и название серии мелко). Где список — наоборот, подпись-надзаголовок мелкая и приглушённая, а содержание несут строки. Подписи блоков — капсом, мелким кеглем: они ориентир, а не заголовок статьи.

**Градиент плиток (только в «Акценте»).** Едва заметный тёплый отсвет от `--color-accent` (5% у обычных плиток, 13% у героя, 10% у просрочки), заданный через `color-mix` от переменной темы — живёт и в тёмной, и в светлой. Сознательно **не неон из трендов**: раздел про спокойствие, а не про диджитал-витрину. Нет поддержки `color-mix` — просто нет градиента, вёрстка цела.

**Пустой экран** (новичок): пустые блоки не рисуем вовсе — вместо них чек-лист из трёх шагов (завести привычку → отметить → поставить цель) с **одним активным призывом**: кнопка только у первого невыполненного. Путь видно целиком, делать нужно одно.

**Постоянство (✅ 2.9)** — плитка «Постоянство» в общем ряду: итог «дней с действием» крупно, окно «X из последних 7» мелко под ним, ссылкой на `/accent/stats`. Рисуется только при `totalDays > 0`.

**Типографика чисел (✅ 2.9).** Где число — герой экрана, оно идёт **крупно, а единица под ним мелким капсом** (`--fs-3xl` + `--fs-xs` uppercase): величина хватается глазом раньше, чем читаются слова. Где плитка мелкая (дашборд) — единица остаётся рядом на базовой линии, столбику там нет места.

**Экран `/accent/stats` (✅ 2.9)** — бенто-раскладка: герой на две колонки + плитка счётчика достижений на одну, ниже «По привычкам» во всю ширину и сетка достижений. Градиенты `color-mix` разной силы (6/9/13%). **Неделя показана точками**, а не полосой: дни дискретны, полоса читалась бы как «процент выполнения»; полоса остаётся там, где есть настоящий потолок (собранные достижения). Полученные достижения — с заливкой и акцентной рамкой, невыданные — пунктиром; свежайшее занимает две колонки. Герой с той же парой чисел (плюс «последняя отметка N дней назад» и «возвращался N раз», если было), список привычек со своим постоянством у каждой и сетка из **пяти** достижений: выданные с датой и деталью момента, невыданные приглушены (`opacity: .62`) и несут подсказку «как получить» — путь виден, а не спрятан. **Шестое, «Вернулся», в сетке не показывается вовсе** (2.9·17, `visibility: 'silent'`): его подсказка была бы инструкцией забросить раздел ради награды, поэтому оно живёт одной строкой в колокольчике — признание момента, а не цель.

**Подсветка цели перехода (✅ 2.9·20, концепт Elmir).** Ссылка, ведущая **в список**, несёт `?focus=<id>`: экран-цель подтягивает нужный элемент в поле зрения и коротко его подсвечивает — три волны по 0,8 с, потом гаснет само. Работает для «Открыть» на дашборде (ведёт к своей задаче в чеклисте) и строки свежего достижения (ведёт к своей карточке в сетке).

- **Зачем.** Переход выбрасывал человека в общий список, где он заново искал глазами то, ради чего кликнул: «Открыть» — в чеклист из восемнадцати строк, достижение — в сетку карточек. Внимание, которое экран сам направил, тут же терялось.
- **Подсветка временная, а не выделение**: осталась бы висеть — стала бы вторым видом «активного» элемента и начала врать.
- **Параметр вычищается из URL** сразу (`replaceUrl`), иначе застрянет в истории и подсветка повторится на «назад» — уже без причины.
- **При `prefers-reduced-motion`** пульсации нет: статичное свечение на то же время, прокрутка мгновенная. Ветка проверена эмуляцией медиа-функции, а не на словах.
- Реализация — **одна директива** `[appFocusTarget]` на все экраны ([`focus-target.directive.ts`](../../../angular/src/app/shared/ui/focus-target.directive.ts)); ссылки на детали (`/goals/:id`, `/anti-habits/:id`) её не используют — там и так конкретная страница.

**Что придёт позже** (дашборд аддитивен — каждая подфаза досыпает свой блок, не переделывая существующие): чек-ин состояния и тренды самочувствия — 2.8; неделя (donut + бары, лучший/худший) — 2.10; «урок-якорь» — с журналом уроков. **XP, уровень и серии не придут** — они отложены в часть 2 геймификации ([паспорт фичи](./gamification-passport.md)).

Desktop ≥1024 — 2 колонки (лево: сегодня+неделя+цели; право: тренды самочувствия (из CheckIn)+серии+достижения+просрочено). Агрегируется одним `GET /accent/dashboard`.

> **Самокомандование (уточнить на 2.11):** «Рекомендации» (п.4, «Сейчас: …») — это директивная команда дня; на финальном дашборде вынести её ближе к ГЕРОЮ экрана (после чек-ина), а не топить в стопке. Дашборд = «делай вот это», не пассивный список.

## 6. Ключевые UX-механики (наши усиления)
- **Минимальная победа на карточке:** вечером, если задача `pending` и серия под угрозой → подсказка «Минимум сегодня: …» (данные уже в задаче, `minVersion`/`ladder.minTarget`).
- **Лесенка вживую:** при `ladder.raised` — мягкий тост «Поднимаем планку: N» (не давление, поздравление). При `lowered` — «Бережём ритм».
- **Анти-привычка:** крупный живой таймер (фронт `setInterval`), circular ring к `targetDays`, кнопка «Сорвался» с подтверждением + поле причины (триггер).
- **Препятствие — «что делать сейчас», а не паспорт проблемы (📋 2.7, [ADR-0062](../../decisions/0062-accent-obstacles-model.md)):** на детали **контрмеры стоят выше** описания/триггера/симптомов. Кнопка «Столкнулся» (карточка и деталь) открывает модалку со **своими контрмерами**: тап по контрмере пишет столкновение и, если она привязана к микро-победе, **сразу запускает её таймер** (ADR-0057); «просто отметить» — запись без контрмеры. Никаких обязательных полей: в плохую минуту человек получает помощь за один тап, а не анкету. Позже — ненавязчивое «Помогло?» (`да / не очень / ×`, можно пропустить); непроставленный ответ нигде не считается негативом. Частота («мешал N раз за 30 дней») подаётся как информация для приоритета, а не счётчик позора; список препятствий — «что мешает», не «твои слабости».
- **Достижение:** модалка `MatDialog` с CSS-конфетти, «Здорово». Звук off по умолчанию.
- **Частичное выполнение:** для quantitative/timed — ввод факта (30 из 50) одним жестом; засчитывается пропорционально, ≥minTarget держит серию.
- **Таймер `timed`-привычки (Трек A / FEAT-H1 — план `2.6.x`):** на карточке `timed`-задачи — кнопка «▶ засечь», открывает фокус-модалку **обратного отсчёта** (переиспользуем таймер микро-побед: подготовка→отсчёт→готово/отмена, звук off по умолчанию). Источник длительности по умолчанию — `ladder.currentTarget` на сегодня, с ad-hoc-переопределением прямо в модалке (саму лесенку не меняет). Семантика зачёта по завершении — H1.1b.

## 7. Компоненты раздела (свои, SCSS)
ProgressBar (прогресс цели: % + полоса — построено в 2.5), **Chart (`app-chart`) — линейный / area-график на ApexCharts за своим wrapper, тема из CSS-переменных, движок заменяем ([ADR-0055](../../decisions/0055-progress-charts-apexcharts.md))**, XpBar, StreakBadge (🔥N), TaskCard (чекбокс/частичный ввод/swipe-перенос), GoalCard, MicroWinChip, AntiHabitTimer, CheckinSlider (1..10), Heatmap (как GitHub), **AttributeRadar (паучья диаграмма баланса атрибутов — [ADR-0028](../../decisions/0028-accent-timezone-and-domains.md))**, EmptyState (с CTA), Toast. Модалки/диалоги — только через MatDialog. (radar и ProgressDonut для недельного % на дашборде — план поздних волн, ещё не построены; модель под них — сразу).

## 8. Онбординг (волна, но заложить)
Короткий: что важно (1–3 сферы) → первая цель (с подсказкой) → первая привычка (из шаблонов) → достижение «Первый шаг» сразу → мини-тур. Прогрессивное раскрытие сложных фич. Для «Васи» — первая победа за ~5 минут.

## 9. ПДн и приватность в UI
На свободных полях (`whyItMatters`, `note`, identity, причина срыва, цель, **а также `name`/`trigger`/`symptoms`/заметка столкновения у препятствий**) — подсказка «не указывай реальные имена/телефоны/адреса» ([ADR-0001](../../decisions/0001-data-minimization-no-pii.md)). В препятствиях (📋 2.7) подсказка особенно нужна: раздел провоцирует писать про конкретных людей («начальник Иван»). Никакой аналитики залипания.
