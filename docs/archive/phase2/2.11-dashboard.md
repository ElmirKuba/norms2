#### 2.11 — дашборд «кокпит» → вышел версией `2.8.0` — ✅ ЗАКРЫТА и на проде 2026-08-04

> **Откуда риск.** По [`ui-ux §5`](./sections/accent/ui-ux.md) кокпит — восемь блоков, но
> собрать сегодня можно три: задачи дня с процентом, цели, просрочку. Остальное ждёт своих
> подфаз: чек-ин и рекомендации — 2.8, XP и серии — 2.9, неделя-donut — 2.10, тренды — 2.8.
> **Герой замысла — директивное «Сейчас»** — приходит с чек-ином, то есть ПОСЛЕ. Сделать
> буквально по плану значило бы получить витрину: четыре вкладки, сложенные в одну страницу, на
> главном месте продукта.
>
> **✅ Решения (Elmir, 2026-08-03):**
> 1. **Герой есть уже сейчас, но считается по правилам** — без чек-ина, из данных, которые уже
>    лежат. Чек-ин в 2.8 не добавит блок, а **уточнит выбор** внутри готового механизма. Плюс
>    честная сводка под ним: герой и сводка — слои, а не альтернативы. (ИИ в критическом пути нет
>    — [ADR-0063](./decisions/0063-no-llm-in-critical-path.md), правила rule-based.)
> 2. **Один `GET /accent/dashboard`** — согласованный снимок за один поход по сети; на мобильном
>    это заметно. Агрегатор строго читающий, собирает через domain-services (кросс-домен вниз).
> 3. **Пустой экран — чек-лист из трёх шагов с ОДНИМ активным призывом:** путь видно целиком,
>    кнопка только у первого невыполненного шага. Ни пустых блоков, ни выбора из пяти дверей.
>
> **Правила героя «Сейчас» (порядок приоритета, первый сработавший побеждает):** просроченная
> разовая задача → незакрытая задача дня → незавершённая микро-победа (когда день закрыт) →
> похвала «на сегодня всё». Тон директивный, но не приказной: одно действие и кнопка, а не список.
>
> **Чего в 2.11 сознательно НЕ делаем:** XP/уровень/серии (2.9), неделя-donut (2.10), тренды
> самочувствия и сам чек-ин (2.8), онбординг-тур (отдельная волна, [`ui-ux §8`](./sections/accent/ui-ux.md)).
> Дашборд **аддитивен**: каждая следующая подфаза досыпает свой блок, не переделывая существующие.

- [x] **·2 (бэк, домен «Сейчас»)** ✅ 2026-08-03 — `AccentNowDomainService.choose()` + тип `DashboardNow`. **Чистая функция над готовыми данными** — ничего не запрашивает сама, всё приходит из агрегатора; поведение проверяемо целиком, без БД. Правила: просрочка (единственное, что уже подвело) → незакрытая задача дня (**первая по порядку** — приоритет внутри дня человек расставил сам, второй раз за него не решаем) → невыполненная сегодня микро-победа (**примеры-витрины не предлагаем**, [ADR-0051](./decisions/0051-starter-habits-inert-showcase.md): пока не забрал себе — не твоё) → «на сегодня всё» (дел **не выдумываем**; пустой день без привычек попадает сюда же — это нормально, а не провал). **Почему отдельный сервис:** это единственное место продукта, которое решает за человека, и оно будет умнеть — в 2.8 сюда придёт состояние из чек-ина; правило, спрятанное внутри сборки ответа, такого роста не переживёт.
- [x] **·3 (бэк, агрегатор)** ✅ 2026-08-03 — `DashboardModule` (свой модуль, **своих таблиц нет и не будет** — дашборд ничего не хранит), `GetDashboardUseCase` + `GET /accent/dashboard`. Восемь запросов идут **параллельно** (`Promise.all`) через domain-services соседей — кросс-домен вниз; для этого `HabitsModule` начал экспортировать `AccentTaskDomainService`, `AntiHabitsModule` — свой domain-service. **API-смоук 22/22 на dev, на свежесозданном аккаунте и на живом.** Проверено: пустой аккаунт даёт `all_done` и нули (дел не выдумываем); появилась привычка → герой предлагает задачу и **дашборд материализовал день**; отметил → 100% и флаг онбординга; примеры-витрины героем не предлагаются; своя микро-победа предлагается; **просрочка перебивает всё**; цель приходит с посчитанным процентом; пауза видна.
  - **Два решения по ходу.** (1) Процент целей считаем **только для показанных пяти** — `describe()` ходит за записями цели, гонять его по всему списку ради сводки незачем. (2) Флаг «отмечал хоть раз» — **по всей истории** (новый `hasAnyCompletion`, один EXISTS), а не по сегодняшнему дню: иначе человек, отметивший вчера, снова увидел бы шаг «отметь» и решил, что его прогресс не считается.

- [x] **·6 (фронт, пустой экран)** ✅ 2026-08-03 — блок «С чего начать» над героем: три шага (завести привычку → отметить → поставить цель), пройденные зачёркнуты, **кнопка только у первого невыполненного**.
